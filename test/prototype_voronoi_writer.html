💡 보로노이 거리 필드 알고리즘 핵심 원리

1. 0.01초 미만 오프스크린 래스터화

임시 메모리 캔버스에 OS 폰트 렌더러가 직접 궁서체 텍스트를 고화질로 렌더링합니다. 글리프의 불투명 픽셀들만 추출하여 좌표 인덱스를 구성합니다.

2. 최단거리 투영(Point-to-Segment Projection)

각 픽셀 $(x, y)$에서 모든 획의 중심선 세그먼트까지의 유클리드 거리를 계산합니다. 가장 짧은 거리를 가진 획 ID($k$)와 진행 파라미터($t \in [0, 1]$)를 $O(N)$으로 바인딩합니다.

3. 번짐 0%의 단조 증가(Monotonic) 노출

애니메이션 진행 시 현재 획 번호와 $t$ 파라미터 조건(pixelStroke == curr && pixelT <= progress)을 만족하는 픽셀만 정확히 깨어나므로 인접 획 번짐이 원천적으로 불가능합니다.
