# EPS-TOPIK 1,917문항 데이터베이스 및 무작위 시험 생성 불변 규칙

이 문서는 한국어능력시험(EPS-TOPIK) 1,917문항 데이터베이스 관리와 CBT 무작위 실전 모의고사 생성 시 반드시 준수해야 하는 핵심 아키텍처 규칙입니다.

## 1. 1,917문항 데이터베이스 다양성 유지 원칙 ([epstopik_1917_bank.js](file:///c:/Myproject/auto_income/epstopik_1917_bank.js))

1. **템플릿 단순 복제 금지**:
   - 문항 데이터베이스는 소수의 문장 틀(예: 특정 안내문, 특정 보호구 대화)에 명사만 치환하는 방식으로 생성하지 않는다.
   - 듣기(L) 25개 카테고리(960문항) 및 읽기(R) 25개 카테고리(957문항)는 각 영역별로 실제 고용허가제 실무 상황(출입국, 금융, 의료, 안전, 공구, 농축어업, 명절문화, 제도 등)에 부합하는 고유한 지문, 보기, 해설을 유지해야 한다.
2. **마스터 40문항 보존**:
   - 제1회차 공식 실전 문항(듣기 1~20번, 읽기 961~980번)은 한국산업인력공단 공개문제집 원본을 정밀하게 보존한다.
3. **글로벌 스코프 3중 바인딩 유지**:
   - 브라우저 및 Node 환경 호환성을 위해 `const EPSTOPIK_1917_BANK`, `window.EPSTOPIK_1917_BANK`, `window.EPS_FULL_1917_BANK`, `globalThis` 바인딩을 항상 유지한다.

## 2. 층화 균등 무작위 추출 알고리즘 ([topik_questions.html](file:///c:/Myproject/auto_income/topik_questions.html))

무작위 랜덤 모의고사 생성 함수 `generateRandomExam()` 실행 시 다음 알고리즘을 필수로 적용한다:

1. **층화 균등 추출 (Stratified Random Sampling)**:
   - **듣기 20문항 추출**:
     - 전체 듣기 25개 카테고리 중 무작위로 서로 다른 20개 카테고리를 선택한다.
     - 선정된 각 카테고리 풀에서 1문항씩 독립 추출하여, 20문항 내에서 카테고리와 문제 유형이 절대 겹치지 않도록 보장한다.
   - **읽기 20문항 추출**:
     - 전체 읽기 25개 카테고리 중 무작위로 서로 다른 20개 카테고리를 선택한다.
     - 선정된 각 카테고리 풀에서 1문항씩 독립 추출하여, 20문항 내에서 영역 중복을 배제한다.
2. **Fisher-Yates 셔플**:
   - 카테고리 선정 및 최종 20문항 배열 시 편향 없는 Fisher-Yates 셔플 알고리즘을 사용한다.
3. **독립성 보장**:
   - 버튼을 누를 때마다 1,917문항 전체 풀에서 새로운 난수로 분산 추출되어 항상 새로운 모의고사가 생성되어야 한다.

## 3. 오디오 및 OMR 연동 규칙

1. **오디오 매핑**:
   - 문항 번호에 맞는 표준 음원(`assets/audio/epstopik/q_XXXX.mp3`)을 1차적으로 탐색하며, 음원이 부재할 경우 Web Speech 자연어 음성 폴백으로 매끄럽게 전환되어야 한다.
2. **OMR 및 채점 동기화**:
   - 무작위 모의고사(`APP_STATE.currentRound = 'random'`)에서도 OMR 카드 마킹, 자동 채점, 상세 해설 모달이 100% 정상 동작해야 한다.
